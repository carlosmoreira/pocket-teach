‹02 · MovesAmplify

Moves vs. copies

Primary source · The Rust Book, ch. 4.1

When you assign a String to a new variable, Rust moves it — the original can no longer be used, like the ownership hand-off in L1.

Small, stack-only types (i32, bool) copy instead, so both stay valid.

After let b = a; where a: String, using a is…
rejected at compile time
allowed and cloned
allowed but unsafe

2 Architecture

3 Core flow — new project → first lesson

Nothing is generated until you approve. The teacher interviews, proposes, and only then runs the two-stage build.

4 Generate a lesson — the SSE sequence

One request, streamed phases, two model calls. The plan event lets the app preview before the writer finishes.

5 Data flow — what actually crosses the wire

A few KB per call. Past lesson bodies never leave the phone — only their recap travels, which is what makes cross-lesson references (“like in L2…”) accurate and tappable.
